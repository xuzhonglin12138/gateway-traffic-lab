# Gateway Traffic Lab 中文流量工具改造设计

## 背景

当前页面用于通过浏览器向 Rainbond 网关发送请求，方便观察网关监控数据。现有页面存在两个问题：一是路径、方法等选择框的实际发送行为不清晰，场景按钮会立即运行并覆盖手动选择；二是页面文案以英文为主，不适合当前使用者。

## 目标

- 修复选择框选择后发送不符合预期的问题。
- 将请求能力分为普通请求、持续请求、压力测试请求三个层级。
- 页面和 README 改为中文。
- 保持浏览器直接发请求，让网关监控能统计真实请求量。

## 设计

前端继续保持无框架单页实现。页面左侧提供模式选择、预设参数和表单配置；右侧展示统计结果、进度和请求日志。

三个请求层级：

- 普通请求：低并发、有限次数，适合验证路径、状态码和延迟。
- 持续请求：按固定间隔持续发送，直到用户点击停止，适合观察网关监控曲线。
- 压力测试请求：高并发、批量请求，保留上限，适合验证网关吞吐和错误率。

选择框修复：

- 预设按钮只填充参数，不自动开始请求。
- 点击开始时统一读取当前表单值。
- 不同路径按后端实际接口组装查询参数，避免默认分支把无效参数塞给不支持的接口。
